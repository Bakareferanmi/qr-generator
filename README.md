# QR Code Generator

A simple command-line QR Code Generator built with Python.

## Features

- Generate QR codes from text
- Generate QR codes from URLs
- Save QR codes as PNG images
- Lightweight and easy to use

## Installation

```bash
pip install qrcode pillow
```

## Usage

```bash
python main.py
```

## Example

Input:

```
https://github.com/Bakareferanmi
```

Output:

```
github.png
```

## Tech Stack

- Python
- qrcode
- Pillow
